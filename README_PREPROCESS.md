# 图片预处理页面（四点透视矫正 + 取色涂抹）

主界面现在是**双页签**：
- **待识别列表**：原有功能，全部不变（拖入/排序/输出设置/开始识别）。
- **图片预处理**：新增，针对当前选中的单张图片做**四点透视矫正**和**取色涂抹**，用于提升 OCR 准确率。

## 使用流程

1. 在“待识别列表”里添加图片并选中一张；
2. 切到“图片预处理”页签，点 **加载当前选中**；
3. 会自动做一次四点矫正（绿色四边形 + ① ② ③ ④ 角点）；
4. 需要时：
   - **拖动角点**：直接拖绿色角点微调四边形；
   - **手动取四点**：当自动识别失败（如表格只占页面一部分、网格线不明显）时，点“手动取四点”，再在图上**依次点击 4 个表格角点**，自动连成四边形；
   - **缩放/平移**：滚轮缩放；放大后拖动右侧/底部的**上下左右滚动条**平移查看（缩小到适应视图时自动居中并禁用滚动）；
   - **吸管取色**：选“吸管取色”后在图上点，取当前像素颜色；
   - **画笔涂抹**：选“画笔涂抹”，用当前颜色覆盖手写笔迹/网格线/噪点/印章；笔刷大小可调；
   - **调色盘**：自绘 HSV 板，也可选任意颜色；
   - **撤销/重做/清空**：多级撤销（最多 20 步）。
5. 勾选要应用的处理项（透视矫正 / 涂抹覆盖），然后：
   - **✍ 保存全部改动**：把**所有已修改**的图片（各自独立的角点+涂抹）一次性写入 OCR 内存缓存，最省事；
   - **应用到当前图**：只处理当前一张；
   - **套用当前参数到全部**：把当前图的角点/涂抹参数套用到列表全部图片（同角度批次用）；
   - **预览矫正结果**：在画布显示矫正后的图；
   - **重置本图** / **重置全部改动**：清除预处理缓存与改动。
6. 回到“待识别列表”，点 **开始识别并生成 XLSX**。识别时对每张图优先使用预处理结果，未预处理的仍走原来的自动矫正。

### 每张图独立的改动 + 已修改标记

- 每一张图都保留**自己独立的**四点角点和涂抹笔迹；切换到别的图再切回来，这些改动仍在。
- **待识别列表**里，已修改（或已缓存）的图片文件名后会显示 **`●已修改`**，一眼看清哪些图处理过。
- “✍ 保存全部改动”会把所有带有改动标记的图片一次性写入内存缓存，无需逐张点“应用到当前图”。

### 右侧工具栏滚动

“图片预处理”页签右侧的工具栏（透视矫正/取色涂抹/操作/应用）在窗体高度不够时会**自动出现纵向滚动条**，不必手动拉长窗体。

### 流畅交互（拖动/涂抹不卡顿）

对**超大原图**（如 4284×5712）不再每帧重编码：底图只在**换图/缩放时**渲染一次并缓存；**拖动角点、涂抹、平移**只重绘轻量的四边形/角点/笔迹覆盖层，因此调整四点和涂抹都很流畅。滚轮缩放才会重建底图。

## 关于“黑边”的说明

透视矫正默认**只输出四边形框选内容，无黑边**。`矫正后加白边` 是可选开关（默认关闭），勾选后会在结果四周加一圈白边缓冲。

## 交互说明 & 说明

- **吸色绘制仅在未矫正原图上涂抹**：涂抹叠加层记录在原图坐标，应用到图片时会先合成涂抹层，再做透视矫正，所以涂抹内容会随矫正一起保留。
- 预处理结果存在内存缓存（键为图片绝对路径），**不覆盖源文件**。点“重置本图”可清除该图的预处理结果。
- 涂抹内容随“预览矫正结果 / 应用到当前图 / 应用到全部图片”写入缓存。同一批图统一处理参数时建议“应用到全部图片”。

## 涉及文件

- `image_preprocess.py`：纯 cv2 逻辑（四边形检测、透视矫正、涂抹合成、颜色换算），可离屏测试。
- `preprocess_frame.py`：预处理页签 UI（画布缩放/平移、角点拖拽、吸管、HSV 调色盘、画笔、多级撤销、批量应用）。
- `table_recognizer_gui.py`：主界面改为 Notebook 双页签；新增预处理缓存 `PREPROCESSED_IMAGES` 与 `set/clear/get_preprocessed`、`load_image_bytes`；识别流程改为优先使用预处理结果。
- `paddle_ocr_vl_adapter.py`：PaddleOCR-VL 识别也优先读取预处理结果。
- `requirements.txt`：新增 `Pillow`（画布显示缩略图用）。
